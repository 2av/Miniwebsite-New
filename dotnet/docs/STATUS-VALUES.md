# ShareBizz status values

Use only these labels. Do not invent alternatives such as Success, Failed, Inactive, or Pending Payment for these columns.

`Expired on date` and `Paid on date` include the real date, for example `Expired on 12-10-2026` and `Paid on 12-10-2026`.

## DB Profile Status

- Active
- Suspended
- Expired on date

## Commission Status

- Not Eligible
- Eligible
- Rejected

## SB Payment Details

- Pending
- Paid on date
- Rejected

## User Status

- Active
- InActive

## Coupon Status

- Active
- InActive
- Expired

The admin chooses only Active or InActive. A coupon shows Expired automatically once its validity date has passed.

## Plan Commission Status

- Active
- InActive

Only Active terms are used for the referrer's sign-up earning.

## Document verification

- Not Submitted
- Pending Review
- Approved
- Resubmission Required
- Rejected
